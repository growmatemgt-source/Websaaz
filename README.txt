WEBSAAZ - final site (portfolio + client finder in one)

1. config.js: naam, WhatsApp, Instagram handle, prices, portfolio edit karo (Notepad se).
2. Vercel: vercel.com > Add New > Project > yeh poora folder upload karo. Build settings ki zaroorat nahi.
3. Deploy ke baad apna link config.js ke siteUrl mein likho aur dobara upload karo.
4. Studio kholne ke liye: website ke footer mein "Studio" dabao ya link ke end mein #studio lagao. PIN config.js mein hai.
5. Naya project add karna ho to config.js ke portfolio mein ek line copy karke badlo.

Note: PIN halka sa lock hai. Koi technical banda config.js dekh kar PIN padh sakta hai, isliye leads mein sirf business ke naam/number rakho.
